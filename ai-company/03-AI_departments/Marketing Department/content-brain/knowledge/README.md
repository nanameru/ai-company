# content-brain knowledge

このフォルダは content-brain（発信脳）専用のナレッジ置き場。

## 置くもの

- 過去の成功した投稿例
- 反応が良かったフック・訴求
- 避けるべき表現・失敗例
- 媒体別のテンプレ（X、note、Brain）
- テーマ候補リスト
- X運用戦術: `openclaw-x-playbook.md`（バズる型・段階別施策）

## 置かないもの

- 顧客の個人情報（→ `01-private/`）
- 未整理の会話ログ丸ごと（→ 要約してから置く）
- 価格・契約の正本（→ `02-company_knowledge/offer.md`）

## 正本との関係

| 種類 | 正本 |
|---|---|
| 事業・サービス | `02-company_knowledge/service.md` |
| オファー・価格 | `02-company_knowledge/offer.md` |
| FAQ | `02-company_knowledge/customer-faq.md` |
| 文体 | `00-rules/writing-style.md` |
| 発信固有の学び | この `knowledge/` |
