# まず覚える基本形

使う場面: どのシナリオにも共通する最小依頼。詳細テンプレは `01-` 以降を使う。

正本: `00-setup/non-engineer-request-kit-v2.md`

---

## コピペ用

```text
やりたいことは「{目的}」です。
対象は「{対象者}」です。
使ってよい情報は「{素材}」です。
使ってはいけない情報は「{禁止素材}」です。
出力は「{形式}」で、「{保存先}」に置いてください。
完成条件は「{確認できる状態}」です。

まずは完成版ではなく、作業範囲と構成案を出してください。
不明点があれば、作業前に質問してください。
```

## 5項目チェック

- [ ] 目的（なぜやるか）
- [ ] 入力（読んでよい素材）
- [ ] 禁止（読まない・触らない・外部操作NG）
- [ ] 出力（形式 + 保存先）
- [ ] 完了条件（人間が確認できる状態）
