# 01-private

個人情報・契約・認証・未公開事業情報の置き場。

## 置くもの

- 顧客の個人情報
- 契約書・NDA
- 請求・支払いの詳細
- 未公開の事業計画
- APIキー・認証情報（可能なら別管理）

## AIの扱い

- 作業依頼で明示的に指定された場合のみ参照する
- 成果物に個人情報を含めない
- 外部送信・公開は禁止（`00-rules/external-action-policy.md` 参照）

## 人間の作業

- このフォルダは `.gitignore` で除外推奨
- 正本は人間が管理し、AI向けには要約版を `02-company_knowledge/` に置く
