# qa-checklist.md

成果物を「作った」と言う前に確認する共通QA。

## 全出力共通

- [ ] 指定された素材だけを使った
- [ ] 保存先が合っている
- [ ] 未確認URL・数値を断定していない
- [ ] 外部公開・送信していない
- [ ] source-map（参照元一覧）がある
- [ ] 次回に使える改善メモを残した

## 出力形式別

| 出力形式 | 追加確認 |
|---|---|
| Markdown記事 | 見出し構造、本文量、読者の痛み、具体例、CTA |
| X投稿 | 文字数、フック、ハッシュタグ要否、リンクの正確性 |
| HTMLページ | スマホ表示、画像、リンク、noindex要否 |
| Excel | シート名、列幅、出典URL、更新日 |
| スライド | 1枚1メッセージ、文字量、PDF化 |

## 完了報告の型

- 何を作ったか
- どこに保存したか
- 何を確認したか
- まだ人間が見るべきこと
