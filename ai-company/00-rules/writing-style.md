# writing-style.md

木村太陽ワークスペース共通の文体ルール。

## 基本トーン

- 簡潔・具体・実務的
- 1文は短く。長い説明は箇条書きに分解する
- 読者の状況（悩み・制約）を先に書く

## 推奨

- 具体例、手順、完了条件を入れる
- 未確認情報は「未確認」「要確認」と明記する
- 次の一歩（CTA）を1つ示す

## NG表現

- 「誰でも簡単に」「確実に稼げる」などの誇大表現
- 根拠のない断定
- 競合の誹謗中傷
- 顧客の個人情報の無断引用

## 媒体別の目安

| 媒体 | 文字量・形式 |
|---|---|
| X投稿 | 140字前後、フック→要点→CTA |
| note / Brain | 見出し構造、具体例、出典明記 |
| メルマガ種 | 件名案 + 3行要約 + 深掘りテーマ |
| LP訴求 | 痛み→解決→証拠→次の一歩 |
