# 依頼文の必須5項目

非エンジニアが AI 社員へ仕事を渡すとき、依頼文には次の5項目を必ず含める。

| 項目 | 書くこと | 例 |
|---|---|---|
| **目的** | なぜやるか | LINE登録者が12大特典を迷わず受け取れるようにする |
| **入力** | 読んでよいもの | 既存フォルダ、ユーザー指定URL、メモ |
| **禁止** | やってはいけないこと | 外部送信、不要ファイル混入、未確認URL断定、01-private/ |
| **出力** | 欲しい形式と保存先 | Markdown → `output/archive/YYYY-MM-DD_slug/` |
| **完了条件** | 人間が確認できる状態 | 開ける、読める、次に何をすればよいか分かる |

## テンプレート

- 索引: `00-setup/WORK_REQUEST_TEMPLATE.md`
- 全文: `00-setup/non-engineer-request-kit-v2.md`
- コピペ用: `00-setup/request-templates/`
  - 初回: `MASTER_FIRST_REQUEST.md`
  - 曖昧時: `UNIVERSAL_CLARIFY.md`
  - 短すぎる: `FEEDBACK_TOO_SHORT.md`

## AI側の動き

依頼に5項目が欠けている場合:

1. いきなり作業しない
2. 5項目に整理して確認する（`UNIVERSAL_CLARIFY.md` と同型）
3. 不明点は最大5つだけ質問する
4. 外部送信・公開・削除が必要なら止まって人間に確認する
